# Typewriter Art 原稿与本地重放

用途：保留用户提供的原稿，说明观察到的绘图规则，便于以后核对与调整本站文字画。这里是研究资料，不是个人网站的运行依赖。

参考链接：https://openprocessing.org/@sihan/2596064

## 文件位置

- `sketch2596064/`：用户提供的五个原始文件，保持未改动。
- `replay.html`：本地重放入口，使用原始绘图代码与三个主题指令；仅把在线主题菜单接到本地下拉菜单。

- `../../previews/typewriter-original-cat.png`：原稿猫主题实际运行截图。

启动网站本地预览后，打开 http://127.0.0.1:4173/references/typewriter/replay.html ，下拉菜单可切换 cat / dog / lady。

## 源码确认的规则

原作以 Bob Neill’s book of typewriter art 的固定指令画图。`2@ 2sp 1:` 表示两个 @、两个空格和一个冒号；1、1a、1b 等同编号行在同一位置套打。字号为 9，行距为 4，纸张为 `#F7F5EA`。它在开始和切换主题时直接画完整图，没有逐字动画。

本站 `../../typewriter.js` 将 meme 或照片明暗转换为字符指令，沿用 4/9 的行距比例及重复套打方式；另加逐步打字、细节调整、拍照和保存。字符自动转换与原稿书籍手工指令是不同来源，呈现质感仍可继续调节。

原网站访问曾受连接验证阻挡；取得用户源码后已通过本地重放观察猫、狗画面。不把先前的验证页面视为原作证据。参考来源和原文件保留在这里，网站的示例图片来源记录在 `../../assets/typewriter-meme-sources.md`。
