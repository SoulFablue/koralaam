# KoraLaam · Look closer

用途：可在本地打开、操作和验收的个人网站。首页包含身份介绍、两份真实作品、常看信息源、个人侧面，以及分别揭幕后独立游玩的日落高尔夫、打字机猜图与通信显示器；第二场景提供教育、工作、作品、爱好四栏目。摄影作品待后续提供并讨论位置。

## 最简单的打开方式

1. 在这个文件夹里找到 `index.html`。
2. 双击，用 Chrome 或 Edge 打开。
3. 想先看头像处理效果，就双击 `avatar-preview.html`。

无需安装网站开发工具，不用注册账号，不依赖在线字体或外部图片。

## 第二个编码作品：打字机文字画

三个作品独立可玩：`#playground` 是高尔夫、`#typewriter` 是文字画、`#almost-understood` 是通信显示器。可以直接打开任一作品，不需要先通关。

1. 高尔夫进洞后留在球场，不触发其他作品；文字画揭开自己的幕布后开始三题猜图。
2. 第三次未进洞回到发球台时，小猫救援出现。点 Put my life in tiny paws，小猫走进画面、伸爪把球推入洞；选择减少动画时直接完成。救援不额外算一杆。
3. 第二件作品标题为 You look human enough.。电脑左侧为文字画、右侧为纵向三个待选原图及确认按钮；手机改为文字画上方、选项下方。一组连续三题，鸟图、Harold 与侧眼猫各出现一次，题目和选项顺序分别打乱。选原图后点 That’s the one；猜错可重试。前两题答对后约 0.65 秒自动进入下一题，三题全对显示完成提示，文字画恢复居中并开放创作。Human check 显示题数；减少动画直接显示成品。
4. 三题全对后点击 Make it me，允许摄像头，再点 Take photo。拍完自动关闭相机，自拍变为文字画，不采集声音。不方便拍照时，Use a photo 可选择不超过 25 MB 的浏览器支持图片，如 JPG、PNG 或 WebP。照片在当前浏览器处理，不上传，刷新不保留。
5. 三题全对后可切换 No birds? / All good. / Side-eye.，Type again 重播，Save print 下载完整 PNG 文字画。展开 A little more detail 可调整密度、彩色墨水与原图对照；原图对照在猜中之前不可用。
6. Three more faces 重新开始一组三题，隐藏创作功能并清空本组进度；三张 meme 重新洗牌，每组不重复。语言切换保留题目、当前题数、已完成数量和选项。

## 第三个编码作品：Through the noise.

直接打开 http://127.0.0.1:4173/#almost-understood ，揭开自己的幕布即可，无需先通关其他作品。保留原链接，内容为暖灰机身、橄榄绿屏的通信显示器。点选 Are you there? / Tell me something kind. / What got lost? / Surprise me.，句子自动逐字敲入，再连续经历编码、受扰、解码与预设回复；不需要手动输入或逐步点下一步。手机发送时自动把显示器带回视野。

1. Noise 从 0% 到 30% 控制每一位被翻转的概率，默认 2%；不是整条消息失败的概率。暖橙色标记实际受扰的位。
2. Try to recover 开启时，每一位发送三份，由接收端取多数票；关闭时只发送一份。CRC-16 校验码随文字一起发送和受扰，用来核对结果，恢复过程不偷看原句。
3. 改变噪声或恢复开关，会在松开调节后自动重发当前消息，略过重复打字。相同句子和设置复用同一串噪声抽签，便于比较，不保证每次都能恢复。高噪声可能让两份以上同时出错，此时请求重发，不冒充读懂。
4. 选句入口在显示器上方，初始屏幕为无光标的等待提示。放大示例依次展示真实的字母→数字→二进制、受扰前后信号、三份取多数及恢复字节→文字；橙色仅标记实际翻转位。点击屏幕底部步骤可停住回看，Send again 重播整段；随时点另一句立即换到新消息。Tab 与 Enter / Space 可操作按钮，方向键可调节噪声。
5. 所有回复均为本地预写文案，没有在线 AI、账号或网络依赖。展开 What happens in between? 可看实际字节数、发送位数、翻转数量与校验结果。不能把校验通过等同于理解语义。
6. 点击 ENCODE 可停住查看每一个字。UTF-8 是共同约定的“文字字典”，例如 A 对应 65；八格的面值是 128、64、32、16、8、4、2、1，亮起 64 和 1 得到 65，所以写成 01000001。中文完整列出多字节数字，再标明当前观察的那一组。字典负责把文字和数字互换，本身不纠错；恢复开关另外把 0 发成 000、1 发成 111。一份被噪声改错时，多数票仍可能恢复；两份都错时也可能失败。
7. 自动播放的 ENCODE 每 160 毫秒轮播一个字符，包括空格和标点，最后停留 240 毫秒再进入传输。选中字母、编码数字及面值同步变化；点击任意字母即可暂停细看，Send again 重播。减少动画时不轮播。

实现见 `signal-monitor.js`；显示器用网页样式和画布绘制，不需要额外图片或三维库。离开画面暂停、回来继续；减少动画直接展示结果。切换语言会按新语言重新编码当前句子；已经完成的消息直接展示新语言结果。旧粒子脚本、样式、翻译与三张旧预览已移除。

## 素材与实现

- 原图保留在 `assets/avatar-original.jpg`，原始附件不修改。
- 头像拆成修补后的脸、两只眼睛和眼镜，使用本地图像修补，保留原图纹理。
- JavaScript 负责弹簧跟随、拖拽捕获、取消与回位，以及文字还原。
- 镜片阅读使用 CSS 椭圆遮罩与词语碰撞检测。
- 图标使用 SVG / CSS；书本封面与纸页在浏览器中旋转，未使用原站的 Three.js 绘图程序。
- 第一阶段头像动作是小幅偏转与眉眼反馈，未制作四画稿网格变形。
- 桌面插画使用 SVG（浏览器可以直接画的图形）与颗粒笔触原创绘制，不需要外部生图或网络图片。固定的纸张颗粒和略不规则的边沿模拟蜡笔质感，和首页共享橄榄绿、暖米色与炭黑色。
- 深圳剪影取平安金融中心的尖顶、市民中心的屋顶形态，仅表达城市，不表示具体学校。作品机器人是装饰，没有冒充真实项目。
- 场景切换时先交接画面，再交接键盘焦点；浏览器前后退跟随场景，返回首页保留原滚动位置。
- 没有分析统计、外部请求或联系表单，不发送个人信息。
- 首页介绍中文逐字、英文逐词测量，既可渐进还原，也可正常换行。旧思考卡阅读代码暂留，当前页面没有思考卡，信息源不参与乱码阅读。
- 球场使用用户提供的 `originals/Dreamy Pastel Sunset Fairway.png`，原文件保留，网站使用 `assets/golf-sunset.png`。背景像一张画，球、轨迹和进洞反馈由浏览器画布叠在画上；图片自带旗杆，代码只补洞口。手机向右取景，保留发球台和旗杆。真实摄影和油画效果尚未实现；此前粒子原型已由通信显示器替代。
- `typewriter.js` 使用浏览器自带画布生成文字画。参考原稿的紧密行距和同一行重复套打；原作使用书籍固定指令，本站从图片生成指令，并添加打字过程，不声称原作自带拍照或照片转换。
